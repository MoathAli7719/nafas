NAFAS - عرض مشروع التخرج

نظرة عامة

منصة تربط الأسر المنتجة والطهاة المنزليين بالعملاء، مع إدارة منتجات وطلبات وإشعارات.

التقنيات: Flutter + Firebase + Cloudinary

أبرز الإنجازات

  • نظام أدوار (Customer / Chef / Admin)
  • إشعارات موجهة من الأدمن
  • رفع صور متعددة بجودة محسّنة
  • إدارة بيانات المطبخ

الهيكلة البرمجية

تطبيق Clean Architecture مع SRP و DRY

  • طبقة Data: Models/Repo Implementations
  • طبقة Domain: Entities/Abstract Repositories
  • طبقة Presentation: ViewModels/UI Pages

قاعدة البيانات

  • users: معلومات المستخدم + الدور + حالة الاشتراك
  • products: المنتجات مع صور متعددة
  • orders: الطلبات مع حالات لحظية
  • subscription_requests: طلبات الاشتراك

الأمان والنشر

  • Firebase Auth + عزل البيانات
  • Keystore & Signing للتطبيق
  • قواعد Firestore

توزيع الفريق

  • معاذ: Leader + Backend + Deployment
  • مريم: واجهات الشيف (Chef UI)
  • هيله: واجهات العميل (Customer UI)
  • آيات: واجهات الأدمن (Admin UI)
